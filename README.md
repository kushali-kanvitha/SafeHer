# SafeHer – Women's Safety Mobile Application

SafeHer is a Flutter-based mobile application designed to support women's personal safety by providing quick access to emergency contacts, safety features, and helpful resources.

The application brings important safety tools together in one simple and user-friendly interface.

## ✨ Features

- **Emergency Contacts:** Add, edit, and delete emergency contacts.
- **SOS:** Quick access to the SOS feature.
- **Fake Call:** Simulate an incoming call when needed.
- **Smart Safety Call:** Interactive simulated conversations for different situations.
- **Location:** Access the location screen to get and share your location.
- **Safety Tips:** View useful personal safety tips.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- Android emulator or physical Android device

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/kushali-kanvitha/SafeHer.git
   ```

2. Navigate to the project directory:

   ```bash
   cd SafeHer
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
